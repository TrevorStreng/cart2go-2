# Cart 2 Go

## Requirements

- [Node](https://nodejs.org/en/)
- [NPM](https://www.npmjs.com/)

## Getting Started

First, make sure you have all of the requirements installed on your local machine.

### Installation

```
# Clone the repository
git clone https://github.com/TrevorStreng/cart2go-2.git

# Navigate to the directory
cd cart2go-2

# Install the dependencies
npm i
```

## Running the application

First, run the application on your machine.

```
npm run dev
```

The application should now be running. Feel free to modify it as you like.
